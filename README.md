# Free Unity VFX

A collection of free, production-ready realtime VFX for Unity by **Vefects**.

Compatible with:

- Built-in Render Pipeline
- Universal Render Pipeline (URP)
- High Definition Render Pipeline (HDRP)

## Installation

1. Download the package for your render pipeline.
2. Open your Unity project.
3. Import the `.unitypackage`.
4. Find the VFX under `Assets/Vefects/`.
5. Drag the desired prefab into your scene.
